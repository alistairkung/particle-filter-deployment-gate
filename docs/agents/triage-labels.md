# Triage labels

| Label | Meaning |
| --- | --- |
| `needs-triage` | Awaiting maintainer assessment |
| `needs-info` | Awaiting information from the reporter |
| `ready-for-agent` | Specified sufficiently for autonomous implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Maintainer has declined the work |
